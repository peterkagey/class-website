1. [3] Prove the following facts about the set \( B_3 \) of $3 \times 3$ matrices that have one $\pm 1$ per row and column.
    1. The identity matrix is in \(B_3\)
    2. If we multiply two matrices in \(B_3\), the result is in \(B_3\).
    3. For every matrix \(A \in B_3\), its inverse is also in the set: \(A^{-1} \in B_3\).
  2. [1] Without looking it up, compute the number of elements in \( B_3 \). (We call this the order of the group.)
  3. [2] Download OpenSCAD, write a module named blob that makes something asymmetrical. You can use any tools that you would like to learn how to do this, but just say which tools you used. Here's my blob, which I display by typing it below the module definition. 
    module blob() {
cylinder(20,10,5);
translate([-5,0,10]) rotate([45,0,0]) cube([20,10,5]);
}

blob();
  4. [4] Apply all possible matrices from part 1 to this using multmatrix(...). (You may want to try to write a program that prints OpenSCAD code instead of doing this by hand.) 
    color("red")
multmatrix([
[0, -1, 0],
[0,  0, 1],
[1,  0, 0]
]) { blob(); }
  5. [1] Do this again, but color the parts whose corresponding matrix has determinant $1$ different from the color of those whose corresponding matrix has determinant $-1$.
  6. [1] Post on the #hw-prompt channel on Discord with a screenshot of blob, a screenshot of all of the rotations of blob, and an STL export of both. (The STL export is likely to take a very long time, as it computes all of the intersections in your blob!)
