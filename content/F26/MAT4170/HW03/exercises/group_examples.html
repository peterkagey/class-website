If an example is a group, prove it; if it is not a group, determine all of the axioms that fail. When checking the axioms, it is important to check closure of the operation, meaning that if \(a, b \in G\), then \(a \star b \in G\).

  1. The natural numbers \(\mathbb N = \{0, 1, 2, 3, \dots\}\) under addition \((\mathbb{N}, +)\).
  2. The integers under addition \((\mathbb{Z}, +)\).
  3. The integers under subtraction \((\mathbb{Z}, -)\).
  4. The integers under multiplication \((\mathbb{Z}, \times)\).
  5. The integers under exponentiation \((\mathbb{Z}, \wedge)\).
  6. The set \(R = \{e, r, r^2\}\) of rotations in \(D_3\).
  7. The set \(F = \{f, rf, r^2f\}\) of reflections in \(D_3\).
  8. The set of \(2\times 2\) real-valued matrices under matrix multiplication \((\mathbb{R}^{2 \times 2}, \cdot)\).
  9. The set $\mathcal{R} = \{1, 5, 7, 11\}$ under multiplication $(\text{mod } 12)$: \((\mathcal R, \times_{\!12})\)
  10. The set of nonzero complex numbers under multiplication \((\mathbb{C} \setminus \{0\}, \times)\).
  11. The set \(A = \{-1, 0, 1\}\) under (ordinary) multiplication \((A, \times)\).
  12. The set \(\mathcal{P}_2 = \{\dots, \frac{1}{16}, \frac{1}{8}, \frac{1}{4}, \frac{1}{2}, 1, 2, 4, 8, 16, \dots\}\) under ordinary multiplication \((\mathcal{P}_2, \times)\).
  13. The set \(\mathcal{B} = \{T, F\}\) under "logical and" \((\mathcal B, \land)\).
  14. The subsets of the integers under set union \((\mathcal P(\mathbb{Z}), \cup)\).
  15. The set of surjective (1-to-1) functions \(\mathcal{F} = \{ f \mid f \colon \mathbb{R} \hookrightarrow \mathbb{R}\}\) under function composition \((\mathcal F, \circ)\).
  16. The set of differentiable real-valued functions under pointwise addition \((C^1, +)\).
  17. The set \(SL_2 = \{ A \in \mathbb{R}^{2 \times 2} \mid A^{-1} = A^T\}\) of \(2 \times 2\) real-valued matrices whose inverse is their transpose under matrix multiplication \((\mathbb{R}^{2 \times 2}, \cdot)\).
  18. The empty set under the empty function \((\emptyset, \circledcirc)\).
  19. The set \(X = \{19\}\) under \(\circledast\) where \(19 \circledast 19 = 19\): \((X, \circledast)\).
