Recall last time that we came up with a provisional definition for a symmetry of a shape: it's something that we can do to the shape where it looks the same afterward. For instance, if we rotate a square \(90^\circ\) about its center, it looks the same as it did before. Recall also, that every shape has a "do nothing" symmetry, which we typically call \(e\).

Dihedral group

Today we will be learning about our first family of groups, called the dihedral group of the regular \(n\)-gon, and denoted \(D_n\). These are the symmetries of the equilateral triangle, square, regular pentagon, and so on.

We know that we can rotate the \(n\)-gon by \(2\pi/n\) radians (or \(360^\circ/n\)) and it will look identical to how it looked before. We also know that we can reflect a polygon across a line that goes through it's vertex or the midpoint of its side. We call these symmetries \(r\) and \(f\) respectively.

When \( n=3 \), the dihedral group \(D_n\) describes the symmetries of an equilateral triangle, which consists of six elements, which we can name in terms of its rotations and reflections. For instance, \(r^2\) means rotate \(120^\circ\) twice (i.e., rotate \(240^\circ\)), and \(rf\) means rotate and then horizontally flip (i.e., flip over the line going through the lower-left corner.)

We chose names for these symmetries, but there are infinitely many other names we could have picked for each. For instance, we could have also called \(e = r^3\) or \(r^2f = fr\) or \(rf = r^{7}f^{7}\).
A group presentation \[ G = \langle S \mid R \rangle \] where \(S\) is a set of elements called generators, and \(R\) is a set of relations, which are words made of out the generators that are defined to be equal to the identity.
We define the dihedral groups in terms of their group presentations.
The dihedral group of the regular \(n\)-gon is the group \[ D_n = \langle r, f \mid r^n = f^2 = (rf)^2 = e \rangle. \]

Now we can use this definition to reduce words, meaning we can simplify a big list of instructions to the resulting instructions. This is an example of doing algebra with symmetries.

Consider the element \[ r^2fr^2fr^3f^4r^2 \in D_4 = \langle r, f \mid r^4 = f^2 = (rf)^2 = e \rangle. \] We can start by noticing that since \(f^4 = (f^2)^2 = e^2\), then this step doesn't do anything, so \[ r^2fr^2fr^3{\color{red}f^4}r^2 = r^2fr^2fr^3r^2 = r^2fr^2fr^5. \] Now we can see that \(r^5 = r^4 r = e r = r\), and so we can further simplify to \[ r^2fr^2f{\color{red}r^5} = r^2fr^2f{\color{red}r}. \]

It might look like we can't reduce our word any further, but that's not the case! The next proposition will show us how to proceed.

In the dihedral group of the regular \(n\)-gon, \[ fr = r^{n-1}f \in D_n. \]
We'll do a trick! Before we flip and rotate (i.e., \(fr\)) we'll first "do nothing" (by rotating \(360^\circ\)), and then after, we'll "do nothing" again (by flipping twice): \[ fr = r^n (fr) f^2 = r^{n-1}r(fr)ff = r^{n-1}(rfrf)f = r^{n-1}f, \] because our group presentation relations tell us that \((rf)^2 = rfrf = e\).
