If we continue to use the provisional definition of symmetry of a shape as "something that we can do to a that shape where it looks the same afterward," then we can expand this to a collection of objects. Suppose we have five identical objects on a table; if we scramble them up, then the collection looks exactly the same as it did before. Maybe we should consider this a symmetry too?

Symmetric group

We call the collection of symmetries that "scramble" or permute a collection of \(n\) objects is called the symmetric group, \(S_n\). There are lots of ways to describe these symmetries: pictures, word notation, cycle notation, and most formally as bijections.

The symmetric group on \(n\) objects, denoted \(S_n\), is the collection of bijections of the form under function composition \[ f: \{1, 2, 3, \dots, n\} \to \{1, 2, 3, \dots, n\}. \]

Word notation

There are two main ways that we describe the permutations in the symmetric group, and the first one that you might come up with on your own is called word notation. Here our words encode permutations and our letters are numbers which represent positions. The first "letter" tells us where to send the first object, our second "letter" where to send the second, and so on.

In the figure above, the first ball goes to position 1, the second to position 5, the third to position 2, and so on. We encode this permutation as the word \[ 152634. \]

We can compose two permutations together to get another permutation, which formally is just function composition.

Let \(\pi = 614253\) and let \(\sigma = 425136\). Compute \(\pi \circ \sigma\). (Recall that composition works right-to-left: first apply \(\sigma\), then apply \(\pi\).)

Cycle notation

Cycle notation is a way of describing a permutation that gives us more insight into its algebraic structure.

Recall that the permutation \(\pi = 152634\), which we illustrated at the top, is a way of encoding the fact that \(1 \mapsto 1 \), \(2 \mapsto 5 \), \(3 \mapsto 2 \), \(4 \mapsto 6 \), \(5 \mapsto 3 \), and \(6 \mapsto 4 \). By rearranging these a bit, we could also write that \[ \begin{align} 1 &\mapsto 1 \\ 2 &\mapsto 5 \mapsto 3 \mapsto 2 \\ 4 &\mapsto 6 \mapsto 4. \end{align} \] To write this in cycle notation, we write \(\pi = (1)(253)(46)\), with the understanding that the number at the end of a parenthetical "wraps around" to map to the number at the beginning.

This tells us that the object that started in position \(1\) will always stay there if we repeatedly perform this permutation. The object that started in position \(2\) will move between positions \(2\), \(5\), and \(3\), and every three "steps" will return to position \(2\). Similarly, the object that started in position \(4\) will alternate between positions \(4\) and \(6\).

Moreover, since the object starting in position \(1\) stays in its position, the objects starting in positions \(2\), \(5\), and \(3\) return to their positions each three steps, and the objects starting in positions \(4\) and \(6\) return to their original positions every other step, we can see that \(\pi^6 = e\).

Note that word notation for a permutation is highly non-unique. For instance, \[ (1)(253)(46) = (532)(1)(46) = (64)(1)(325). \] Moreover, we often follow the convention that "fixed points," which are positions that map to themselves, are often left out of the list entirely, so we usually write \[ (1)(253)(46) = (253)(46). \]

We refer to the groupings of numbers in parentheses as "cycles", so \((1)\) is a length-\(1\) cycle (sometimes called a \(1\)-cycle), \((253)\) is a \(3\)-cycle, and \((46)\) is a \(2\)-cycle.

Remember, we're defining the symmetric group as bijective functions under function composition, so we apply left to right. If \(\sigma = (1436)(52)\), then \[ \pi \circ \sigma = (253)(46) \circ (1436)(52) = (16)(234), \] because \(\sigma\) sends the object in position \(1\) to position \(4\), but then \(\pi\) moves the object from position \(4\) into position \(6\). Thus under the composition, the object in position \(1\) ends up in position \(6\). We can continue on this way to see the object in position in position \(6\) ultimately ends up back in position \(1\), completing this cycle.
