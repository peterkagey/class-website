A coset example

Our first introduction to cosets came up when we studied modular arithmetic. We saw that \(4 \mathbb{Z}\) is a subgroup of \(\mathbb{Z}\), and its cosets are the following: \[ \begin{alignat*}{2} 4\mathbb{Z} &= \{\cdots,-8,-4,0,4,8,\cdots\} &&= 4\mathbb{Z} + 8 \\ 4\mathbb Z+1 &= \{\cdots,-7,-3,1,5,9,\cdots\} &&= 4\mathbb Z+5 \\ 4\mathbb Z+2 &= \{\cdots,-6,-2,2,6,10,\cdots\} &&= 4\mathbb Z+(-6)\\ 4\mathbb Z+3 &= \{\cdots,-5,-1,3,7,11,\cdots\} &&= 4\mathbb Z+403 \end{alignat*} \] We note that these cosets partition \(\mathbb{Z}\) (meaning that every integer appears in one and only one coset), and we emphasize that these cosets have lots of different names (one for each element)!

Cosets as an equivalence relation

Let \((G,*)\) be a group, and suppose \(H \leq G\) is a subgroup. Let the relation \(R\) where \(a \mathbin{\mathrm{R}} b\) if \[ a \in bH = \{ b * h \mid h \in H \}. \] Then this relation is an equivalence relation.

Note that this is equivalent to saying that \(a \mathbin{\mathrm{R}} b\) if and only if \(a = b * h\) for some \({h \in H}\).

We check that \(R\) is reflexive, symmetric, and transitive.
Reflexive.
Since \(H\) is a subgroup, \(e \in H\), and thus \(a = a * e \in aH\).
Symmetric.
Suppose \(a \in bH\), meaning that \(a = b*h\) for some \(h \in H\). Then \[ a*h^{-1} = (b*h)*h^{-1} = b*(h*h^{-1}) = b*e = b. \] Since \(H\) is a group, it contains all inverses, so \(h^{-1} \in H\). Therefore \[b = a * h^{-1} \in aH.\]
Transitive.

Lagrange's theorem

Lagrange's theorem states that the order of a subgroup divides the order of its parent group when that parent group is finite.

Let \((G,*)\) be a finite group with subgroup \(H \leq G\). The order of \(H\) divides the order of \(G\).

We prove this theorem by using the fact that cosets are equivalence classes (shown above) together with the lemma (proposition) below, which shows that all of these equivalence classes are the same size as the subgroup \(H\), meaning that we can partition \(G\) into parts of size \(H\).

Given a subgroup \(H \leq G\), the cardinality of \(H\) is equal to the cardinality of each of its cosets \(aH\).

We will prove that the map \(f \colon H \to aH\) given by \(f(h) = a * h\) is a bijection by showing that it has a two-sided inverse, namely \(f^{-1}\colon aH \to H\) where \({f^{-1}(x) = a^{-1} * x}\). We can check this directly:
