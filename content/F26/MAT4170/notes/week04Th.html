Examples of cosets

Cosets as an equivalence relation

Let \((G,*)\) be a group, and suppose \(H \leq G\) is a subgroup. Let the relation \(R\) where \(a \mathbin{\mathrm{R}} b\) if \[ a \in bH = \{ b * h \mid h \in H \}. \] Then this relation is an equivalence relation.

Note that this is equivalent to saying that \(a \mathbin{\mathrm{R}} b\) if and only if \(a = b * h\) for some \({h \in H}\).

We check that \(R\) is reflexive, symmetric, and transitive.
Reflexive.
Since \(H\) is a subgroup, \(e \in H\), and thus \(a = a * e \in aH\).
Symmetric.
Suppose \(a \in bH\), meaning that \(a = b*h\) for some \(h \in H\). Then \[ a*h^{-1} = (b*h)*h^{-1} = b*(h*h^{-1}) = b*e = b. \] Since \(H\) is a group, it contains all inverses, so \(h^{-1} \in H\). Therefore \[b = a * h^{-1} \in aH.\]
Transitive.
