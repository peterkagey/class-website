Today we will discuss two topics: polynomial rings and units.

Polynomial rings

Let \((R,+,\times)\) be a commutative ring. We say that the polynomial ring \[ R[x] = \{ r_0 + r_1 x + \dots + r_n x^n \mid r_i \in R \} \] consists of polynomials in the variable \(x\) with coefficients in \(R\), under ordinary polynomial addition and multiplication.

As you might expect, a multivariate polynomial with coefficients in \(R\) and variables of \(x\) and \(y\) is written \(R[x,y]\).

We can also use the same notation to adjoin elements and extend the ring.

Let \(\phi = (1 + \sqrt{5})/2\) denote the golden ratio which is a root of the polynomial \(x^2 - x - 1\), meaning that \(\phi^2 = \phi + 1\). We can adjoin \(\phi\) to a ring such as \(\mathbb{Q}\), which means that we construct the smallest ring that contains all of \(\mathbb{Q}\) and also includes \(\phi\): \[ \mathbb{Q}[\phi] = \{ a + b\phi \mid a, b \in \mathbb{Q} \}. \] Note that \(\phi^2 \in \mathbb{Q}[\phi]\) because we can write it as \(\phi^2 = \phi + 1\).
Let \(\phi = (1 + \sqrt{5})/2\) denote a root of the polynomial \(x^2 - x - 1\). Determine the values of \(a_2\) and \(b_2\) such that \[ (a_1 + b_1\phi)(a_2 + b_2\phi) = 1, \] and use this to prove that \(\mathbb{Q}[\phi]\) is a field.

Units

Later we will study a small amount of algebraic number theory which asks questions about how certain rings are similar or different from the integers. For instance, the Fundamental Theorem of Arithmetic tells us that every integer has a unique prime factorization—if we ignore the order of factors and ignore signs. When attempting to generalize ideas like this to other rings, it's useful to pay attention to which elements have multiplicative inverses.

Let \((R,+,\times)\) be a ring. We call an element \(r \in R\) a unit if there exists a multiplicative inverse \(r^{-1}\) in the ring.

Later we will see that if we are in a special kind of ring called a unique factorization domain, then every element can be written uniquely as a product of irreducible elements (kind of like prime numbers) up to reordering and multiplying by units.

Note that a field is precisely a commutative ring with at least two elements such that all nonzero elements are units.

The units in the Gaussian integers \( \mathbb{Z}[i] = \{a + bi \mid a, b \in \mathbb{Z}\} \) are precisely the elements of the set \(\{1,i,-1,-i\}\).

First, we check that all of the elements in \(\{1,i,-1,-i\}\) are indeed units: \({1 \times 1 = 1}\), \({i \times -i = 1}\), \({-1 \times -1 = 1}\), and \({-i \times i = 1}\).

Next, we borrow the norm from complex analysis: \[ \operatorname{norm}(a + bi) = \sqrt{a^2 + b^2}. \] Observe that if \(z_1, z_2 \in \mathbb{C}\), then \(\operatorname{norm}(z_1z_2) = \operatorname{norm}(z_1)\operatorname{norm}(z_2).\) (Check!)

Since \(a, b\) are integers, if \(a + bi \neq 0\), then \(\operatorname{norm}(a + bi) \geq 1\). If \(z_1z_2 = 1\), then \[ \operatorname{norm}(z_1)\operatorname{norm}(z_2) = \operatorname{norm}(1) = 1, \] and it must be the case that \(\operatorname{norm}(z_1) = \operatorname{norm}(z_2) = 1\).

The only four elements \(a + bi \in \mathbb{Z}[i]\) with \(\operatorname{norm}(a + bi) = 1\) are \(\{1,i,-1,-i\}\), which we already checked have multiplicative inverses.
