  2. Look up pictures of an icosahedron, dodecahedron, icosidodecahedron, rhombic triacontahedron, and disdyakis triacontahedron. And guess which ones have the most symmetries and which have the fewest. Then click below to see how many symmetries each of them has.
    Polyhedral symmetry count Trick question. They all have precisely the same \(120\) symmetries, called the icosahedral symmetry group \(I_h\).
  3. Since rotations and reflections are linear transformations, we can represent the icosahedral symmetry group \(I_h\) as a colletion of \(120\) matrices, each corresponding to a rotation or reflection. We can do this in Mathematica with 
    IcoG = FiniteGroupData["Icosahedral", "MatrixRepresentation"]
    This code creates a variable IcoG, which consists of a list of 120 matrices. (If we put a semicolon at the end of that line, it will assign the variable, but it won't fill your screen with the list. Do that!)
  4. We can check that this list indeed contains \(120\) matrices by Length[IcoG].
  5. We can access the \(i\)-th item in the list with IcoG[[i]]. Mathematica, uses \(1\)-indexing, so the first item is IcoG[[1]] and the last is IcoG[[120]]. If you highlight the output and right-click, you can "Copy As > LaTeX." Do this and paste in the \(19\)th matrix in IcoG.
  6. In Mathematica, we describe the vector \((1, 2, 3)\) as {1,2,3}. Given a matrix IcoG[[120]], we can do matrix multiplication with a period: IcoG[[120]].{1,2,3}. Where does the second matrix in the list send the vector \((0,0,1)\)?
  7. In Mathematica, we can use Table to make a list of objects. In particular 
    Table[M . {9, 1, 9}, {M, IcoG}]
    will walk through every M in IcoG, and perform the matrix multiplication M . {9, 1, 9}. The result is a list of \(120\) points, one for each symmetry of the icosahedral group applied to the point \((9,1,9)\).
