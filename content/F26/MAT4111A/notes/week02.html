Inequalities

There are two inequalities that you will see come up frequently in contest problem writeups, the "AM-GM" (Arithmetic mean-Geometric mean inequality) and the Cauchy-Schwarz inequality.

QM–AM–GM–HM inequality

The (Quadratic mean)–(Arithmetic mean)–(Geometric mean)–(Harmonic mean) inequality states that if \(x_1, x_2, \dots, x_n\) are nonnegative real numbers, then \[ \begin{align*} \sqrt{\frac{x_1^2 + \dots + x_n^2}{n}} &\ge \frac{1}{n}(x_1 + x_2 + \dots + x_n) \\ &\ge \sqrt[n]{x_1 \cdot x_2 \cdots x_n} \\ &\ge \frac{n}{x_1^{-1} + \dots + x_n^{-1}} \end{align*} \]

Last time one of the problems you explored was Nesbitt's inequality, which has a Wikipedia page full of solutions.

If $a, b, c$ be real and positive, prove that \[ \frac{a}{b+c} + \frac{b}{a+c} + \frac{c}{a+b} \geq \frac{3}{2} \]

Problem 15114, The Educational Times and Journal of the College of Preceptors
Hint #1

Here's one approach: note that what you're trying to prove is equivalent to \[ \left(\frac{a}{b+c} + 1\right) + \left(\frac{b}{a+c} + 1\right) + \left(\frac{c}{a+b} + 1\right) \geq \frac{9}{2}, \] and then replace each new \(1\) with something like \( (b+c)/(b+c) \).

Hint #2

We begin by following the hint, and will prove the equivalent statement that \[ \begin{align*} &\left(\frac{a}{b+c} + 1\right) + \left(\frac{b}{a+c} + 1\right) + \left(\frac{c}{a+b} + 1\right) \\ &\qquad= \frac{a + b + c}{b + c} + \frac{a + b + c}{a + c} + \frac{a + b + c}{a + b} \\ &\qquad \geq \frac{9}{2}. \end{align*} \] We let \(x_1 = \displaystyle \frac{a + b + c}{b + c}\), \(x_2 = \displaystyle \frac{a + b + c}{a + c}\), and \(x_3 = \displaystyle \frac{a + b + c}{a + b}\).

Solution write-up

Using the work from the hints above, we compute the quadratic mean: \[ \frac{3}{x_1^{-1} + x_2^{-1} + x_3^{-1}} = \frac{3(a+b+c)}{(b+c) + (a+c) + (b+a)} = \frac{3}{2} \] By the AM–HM inequality, \[ \frac{1}{3}(x_1 + x_2 + x_3) \geq \frac{3}{2}, \] establishing the desired inequality.

Cauchy-Schwarz inequality

(See AoPS) For any real numbers $a_1, a_2, \dots, a_n$ and $b_1, b_2, \dots, b_n,$ \[ (a_1^2 + \dots + a_n^2)(b_1^2 + \dots + b_n^2) \geq (a_1b_1 + \dots + a_nb_n)^2, \] and this inequality is equal precisely when the vector \(\vec{a} = (a_1, a_2, \dots a_n)\) is a scalar multiple of \(\vec{b} = (b_1, b_2, \dots, b_n).\)

Hint #1

Take \(a_1 = \dots = a_4 = 1\) and let \(b_1 = a\), \(b_2 = b\), etc.

Hint #2

Now we know that \((1+1+1+1)(a^2 + b^2 + \dots + d^2) \geq (a + b + c + d)^2,\) and we know that \[ \begin{align*} (a^2 + b^2 + c^2 + d^2) &= 16 - e^2 \\ a + b + c + d = 8 - e. \end{align*} \]

Solution write-up

Now use the face that \(4(16-e^2) \geq (8-e)^2\) and solve for \(e\) to get that \(e(5 e - 16) \geq 0\), and thus \(e \in [0, 16/5]\).
