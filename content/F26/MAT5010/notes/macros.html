In these notes, I will show you how to make some basic macros using \newcommand{...}[...]{...}.

Macros as alias

The most common first use of macros is to give an alias to commands. For example, we can typeset \(\mathbb{Z}\) using the code \mathbb{Z}. This is a little annoying to type, so you can add \newcommand{\Z}{\mathbb{Z}} to your preamble, and this allows you to instead just write in your code \Z when you want to use this time.

  1. Write some aliases using \newcommand, and post on the "Macros" thread in the #hw-prompts channel of our Discord channel. (Make sure that you don't name your alias something that already exists as a command.)
  2. Sometimes you want to overwrite an existing command. See what \epsilon looks like, and then add \renewcommand{\epsilon}{\varepsilon} to your preamble. How does \epsilon look different now?
  3. There are also built-in codes that you can overwrite in order to change their values. Add \renewcommand{\baselinestretch}{2} to your preamble. What happens?

Macros as functions

We also can use \newcommand to define functions which take one or more parameters. For instance, instead of writing \langle r,f \mid r^4=f^2=(rf)^2=e \langle, I have defined a macro 

\newcommand{\pres}[2]{\langle #1 \mid #2 \rangle}
so that I can instead type \pres{r,f}{r^4=f^2=(rf)^2 = e}.

The example above illustrates how the \newcommand syntax works. The first argument (in curly braces {...}) gives the name of the function. The second argument (in square brackets [...]) specifies the number of parameters. The third argument (in curly braces {...}) gives the function definition, where #1 refers to the first argument, #2 refers to the second argument, and so on.
