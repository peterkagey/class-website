Using a class file (.cls) is easy! For instance, if the class file is called CPP.cls, just put the file in the same directory as your .tex file, and reference it with \documentclass{CPP} at the top of your file. For your thesis, don't touch the class file.

Go to the current students page on the department website, and scroll down to the section titled "LaTeX Thesis Template Files." Follow the instructions by downloading the files, and putting them next to each other in the same directory.

I've never written my own class, and you will probably never have to. However, you can read about how to write a class file in the Overleaf docs.
