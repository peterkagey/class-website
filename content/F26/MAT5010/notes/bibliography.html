Citations are a critical part of articles, theses, and other mathematical writing. The most common tool for managing citations is biblatex. A good place to learn about this package is via the Overleaf documentation for bibliography management.

Your .bib file

You will store all of your bibliography data in a file called with the .bib extension, which has various kinds of data templates, such as article, book, and misc. 

@article{Valiant1979,
  title = {The complexity of computing the permanent},
  journal = {Theoretical Computer Science},
  volume = {8},
  number = {2},
  pages = {189-201},
  year = {1979},
  issn = {0304-3975},
  doi = {https://doi.org/10.1016/0304-3975(79)90044-6},
  url = {https://www.sciencedirect.com/science/article/pii/0304397579900446},
  author = {L.G. Valiant}
}

@book{Stanley2011EC1,
  author = {Stanley, Richard P.},
  title = {Enumerative Combinatorics: Volume 1},
  year = {2011},
  isbn = {1107602629},
  publisher = {Cambridge University Press},
  address = {USA},
  edition = {2nd}
}

@misc{MSELoop,
  title = {The unique loop (quasigroup with unit) $L$ of order $5$ satisfying $x^2 = 1$ for all $x \in L$},
  author = {Travis Willse},
  howpublished = {Mathematics Stack Exchange},
  note = {URL:https://math.stackexchange.com/q/1216907 (version: 2018-12-27)},
  eprint = {https://math.stackexchange.com/q/1216907},
  url = {https://math.stackexchange.com/q/1216907}
}

You can often export the citation from a journal's website!

  1. Make a file called HW5.bib next to your .tex file.
  2. Find an article online such as the Valiant article above, and see if you can export the bibliography. On ScienceDirect, you will click "export" and then "Export citation to BibTeX". (If this downloads a file, open it up, and copy/paste the relevant citation into your file.)
  3. Find a physical book, and build a @book entry either by hand or by using a web tool (like an ISBN to BibTeX converter). Note that each template has different requirements which you can read about here. For example a book requires either an author or editor along with a title, publisher, and year.

Including a citation

Once you have your bibtex file, you're ready to start citing!

  1. Make sure to add 
    \usepackage{biblatex}
\addbibresource{HW5.bib}
    to your header.
  2. Now cite one of the entries in the body of your document with, for example, \cite{Stanley2011EC1}.
  3. Wherever you want the bibliography (typically either before the appendix or before the end of the document), put \printbibliography.
