Columns

I rarely use multiple columns, but when I do, I use \usepackage{multicol} to my preamble.

Put some text in the multicols environment, and specify how many columns you want

\begin{multicols}{2}
  Put your text here!
\end{multicols}

Minipage

I do use minipages a fair amount, which allows you to specify column width and contain your code. Basically what a minipage does is allows you to specify a width of a box, and then it treats what's in that box like its own page, which will not interact with other things on the page. It is common to use this if you want to have text on the left and an image on the right.

Tip! When you're figuring out the layout, wrap your minipage in a \boxed{...} (which requires the amsmath package). This helps you to see the boundaries of your minipage.

Start by copy/pasting the following into your document, making sure to rename example.png.

\boxed{\begin{minipage}{0.5\linewidth}
  Put some text in this minipage.
\end{minipage}}
\boxed{\begin{minipage}{0.5\linewidth}
  \includegraphics[width=1cm]{example.png}
\end{minipage}}
  1. You will notice that the first minipage is (probably) indented. Add \noindent before the first minipage.
  2. If you've typed a lot of text, you'll notice that it bumps right up against your image. Make one of the minipages narrower, and add whitespace between them, probably with \hfill
  3. That image is small, right? Change its width to [width=\linewidth], which will make the width of the image match the width of the minipage.
  4. I usually like my minipages top-aligned. Use \begin{minipage}[t] where t stands for top.
  5. When everything looks how you want it to, remove the \boxed wrapper.
