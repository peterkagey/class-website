Default environments

There are many different environments that we use when writing \(\LaTeX\) to make lists, tables and more.

List environments

In many writing contexts, especially when writing multi-part homework assignments, we want to make numbered lists. We do this with the enumerate, itemize, and descriptionenvironments.

Enumerate

The enumerate environment makes numbered lists using the following syntax: 

\begin{enumerate}
  \item First item in list.
  \item Second item in list.
\end{enumerate}

As you nest these environments, it will automatically change the numbering style from numbers to letters to roman numerals and so on.

Itemize

The itemize environment makes bulleted lists using the following syntax: 

\begin{itemize}
  \item First bullet in list.
  \item Second bullet in list.
\end{itemize}

Again, as you nest these environments, it will automatically change the sub-bullet style.

Description

The description environment allows you to start each item with words, which you explicitly add to each \item. 

\begin{description}
  \item[Case 1.] First case in a proof.
  \item[Case 2.] Second case in a proof.
\end{description}
