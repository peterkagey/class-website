This week we will discuss numbering and internal references via \ref, \label, the package cleveref, and tables and figures.

Section numbering

The standard way of labeling sections and subsections is with \section{Section title} and \subsection{Section title}. If you want an unnumbered section, use an asterisk: \section*{Section title}.

When using the default numbering, anything before the first section is considered Section 0.0, and then the sections and subsections increment in the expected way. If you want to use an appendix, use \appendix, and then the subsequent appendix sections will be labeled A, B, C, etc.

Begin by adding at least one section and subsection, and appendix, and at least one appendix section and subsection.

Labels and references

When writing an article, thesis, or other substantial document, it is very common to refer back to previous work in the document or to preview later work. We do this by labeling our section, theorem, figure, table, equation, or other environment with \label{name-of-reference}. We can then reference the corresponding number (but not environment) with \ref{name-of-reference}. If you \usepackage{cleveref}, then you can reference the environment name and number with \Cref{name-of-reference}.

You can label these however you'd like, but I recommend labels which remind you of the environment and the content using labels such as \label{thm:Pythagorean}, \label{lem:Burnside}, \label{ex:invertible-matrix}, or \label{eq:binomial-identity}.

  4. Make sure your preamble includes \usepackage{cleveref} and then reference the theorem again via \Cref{thm:example-theorem}. Which way do you prefer?
  5. You use \ref{...} to refer to theorems, propositions, lemmas, examples, remarks, etc. However, when referring to equations, you should use \eqref{...}. Figures, graphics, and tables

We can add figures with the following code: 

\begin{figure}
  \centering
  \includegraphics[width=0.5\linewidth]{path/to/image.ext}
  \caption{This is the caption.}
  \label{fig:example-image}
\end{figure}

By default, figures float, meaning that they won't necessarily go right where you put them, but instead they will go where the \(LaTeX\) compiler thinks they fit the best. It is a writing convention that you must always refer to your figure somewhere in the body of your document.

Upload a png or jpeg and place it in the same folder as your .tex file. Include it as a figure by using the above code, and then refer to it somewhere in the body of your document (outside of the figure environment.) Most of the time that there are images in our document, they belong in figures.

Tables

Tables behave a lot like figures—in particular, they also float. Sometimes theses and other documents will catalog the figures and tables and reference them at the beginning of the document as a "list of tables" and a "list of figures."

Use the following code to add (and label, and refer to) a table. 

\begin{table}
  \centering
  % Put a table here, using the code from last week.
  \caption{This is the table caption.}
  \label{tabl:example-table}
\end{table}

Look up how to add a list of figures and a list of tables to the beginning of the document and add both.
